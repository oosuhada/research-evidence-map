# Signal Garden

Standalone high-fidelity prototype for an AI product-discovery canvas that turns customer evidence into traceable opportunities.

## Run locally

```bash
corepack pnpm install
corepack pnpm dev
```

Open http://localhost:3101.

## Quality checks

```bash
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm build
```

This repository is self-contained and does not depend on the original `ai-ux-mvp-lab` workspace.
